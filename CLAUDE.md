# Claude Code entry point

At the beginning of every task in this repository:

1. Read `docs/handoff.md` for the current snapshot, uncommitted work, next task, and exact resume commands.
2. Read `docs/progress.md` for verified implementation status and known limitations.
3. Read the relevant section of `docs/study-support-plan.md` before making product or behavior decisions.
4. Read `docs/content-generation-design.md` before changing kanji source data, review batches, or generation scripts.
5. Read the relevant ADR before changing an established architectural decision.

Treat those documents as canonical. Keep this file short and do not copy changing counts or task status into it.
