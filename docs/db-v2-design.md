# IndexedDB v2 実装設計

Date: 2026-08-14

毎日の漢字学習を実装する前提として、既存データを維持したまま当日セッションと漢字別集計を扱える保存層へ更新する。

## 対象と対象外

- 対象：DB v1→v2移行、当日セッション保存、回答・セッション・漢字集計の原子的更新
- 対象外：10問の選定アルゴリズム、ホーム進捗画面、バックアップ・復元

## 状態・操作表

| 状態／操作 | 許可する結果 | 拒否または維持する結果 |
| --- | --- | --- |
| v1からv2を開く | 既存履歴・未習設定・旧フィールドを保持し、新集計初期値とセッション索引を追加 | 旧レコードを削除・初期化しない |
| 新規セッションIDを保存 | 固定問題列と全項目のpending状態を追加 | 問題0件、重複項目ID、不正日付を保存しない |
| 同一セッションを再保存 | 内容が同じならduplicate | 異なる内容で上書きしない |
| 現在項目へ誤答 | 回答追加、項目をin-progress、対象漢字の苦手度を1回だけ増加 | 別項目・別形式を更新しない |
| 誤答後に正解 | 項目をcompleted、次の項目へ進む | 先の苦手度増加を相殺しない |
| 初回正解 | 項目をcompleted、対象漢字の苦手度を1回だけ減少 | 下限0を割らない |
| 書き問題を完了 | 文字別結果に従って各漢字を個別更新 | 語句全体へ一律の結果を付けない |
| 同一回答IDを再保存 | duplicateとして何も再更新しない | 回答・集計・進捗を二重計上しない |
| 同一IDの異なる回答 | トランザクション全体を拒否 | 既存回答・集計・進捗を変えない |
| 順番外・完了済み項目へ新規回答 | トランザクション全体を拒否 | 回答だけを部分追加しない |
| 途中で要求が失敗 | 全ストアをロールバック | 履歴と集計が不一致の部分成功を残さない |

## 自動テスト

- v1の回答、履修状態、旧フィールドを保持してv2へ移行する。
- sessionsへ日付・形式索引が追加される。
- セッション作成が同一内容で冪等、別内容で拒否される。
- 読み誤答が `targetKanji` 全字を1回ずつ増加させる。
- 読み誤答後の正解が苦手度を減らさない。
- 初回正解が苦手度を下限0まで減少させる。
- 書きの文字別ミス・見本使用を別々の漢字へ反映する。
- 同一回答IDの再試行で回答、集計、セッションが二重更新されない。
- 順番外、存在しないセッション、競合回答IDで全ストアが不変となる。

人による確認は、既存のXiaomi Pad 6上の未習設定と回答履歴が更新後も表示されること。画面接続後に実施する。
