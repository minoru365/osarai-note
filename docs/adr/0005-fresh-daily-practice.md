# ADR-0005: 「今日の漢字」は押すたびに新しく抽出する

- Status: Accepted
- Date: 2026-08-14
- Supersedes: ADR-0003の再開判断、ADR-0004-practice-frequency-firstの固定乱数・当日未出題優先

## Context

「今日の漢字」は、前回の10問を再開する入口ではなく、その時点で練習頻度が少ない漢字を気軽に練習する入口にしたい。固定セットや当日出題済み判定を残すと、押し直したときの抽出が現在の学習回数を反映しにくい。

## State / operation

| 操作 | 問題セット | 回答履歴・漢字別集計 |
|---|---|---|
| ホームで「今日の漢字」を押す | 必ず新しい最大10問を作る | 変更しない |
| 読み／書きタブを押す | 切替先で新しい最大10問を作る | 変更しない |
| 正解を確定する | 現在位置を進める | 原子的に保存する |
| ホームへ戻る／アプリを閉じる | 未完了セットは再開しない | 確定済み記録は保持する |
| もう10問を押す | 新しい最大10問を作る | 変更しない |

## Decision

- 対象モードの漢字別 `presentations` が少ない問題から選ぶ。
- 同じ練習回数の候補は、開始ごとに変わる乱数で並べる。苦手度や当日出題済みかどうかは同順位の並びに使わない。
- 同一セット内では対象漢字の重複を避け、候補不足時のみ重複を許す。
- 未履修漢字を含む問題は候補から除外する。
- セッション記録は回答の原子性と学習実績のため保持するが、次回開始時の再開元・除外元には使わない。
- ホームには当日確定した読み・書きの累計問題数を表示し、「つづきから」は表示しない。

## Mechanical gates

- 練習回数の少ない問題が先に選ばれる。
- 同数候補は同じ乱数シードで同順、異なるシードで異なる順になる。
- 未完了セットがあっても、新しいセッションと問題抽出を作る。
- 新規抽出で当日出題済み問題を除外しない。
- 回答保存のトランザクションと未履修再検査は変更しない。

## Consequences

- 押し直すたびに現在の練習頻度を反映したセットになる。
- 未完了位置は再開されない。
- 過去のセッションは学習実績として残るため、DB移行や削除は不要。
