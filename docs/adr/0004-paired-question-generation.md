# ADR-0004: 共通素材から読み・書きペアを生成

- Status: Accepted
- Date: 2026-08-14

## Context

3・4年生402字の各音訓読みを問題化すると件数が多く、読みと書きを別管理すると内容のずれと保守作業が増える。

## Decision

- 生成単位を「学年 × 主対象漢字 × 音訓区分 × 読み」とする。
- 各単位に共通素材を1件作り、同じ `pairId` の読み問題と書き問題を各1件生成する。
- 語句全体の読みはひらがなに統一する。
- 読み・書きで共用する語句内の漢字は、その問題の学年までに習う文字へ限定する。
- 問題学年より上で習う漢字は、対象漢字を除いて文中の読みでひらがな化する。
- 機械検査後、人が読み、送り仮名、自然さ、学年相当性を全件確認する。
- 確認済み素材だけを公開問題パックへ含める。

## Consequences

- 読み・書きの内容とID対応を一貫して保てる。
- 基準一覧、共通素材、生成物、レビュー状態を分離して管理する必要がある。
- 自動生成だけでは公開できず、全件レビューの運用が必要になる。
