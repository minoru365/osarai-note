# ADR-0002: 漢字単位の読み・書き集計

- Status: Accepted
- Date: 2026-08-14

## Context

同じ漢字が複数の語句・問題へ現れるため、問題IDだけの成績では本当に苦手な漢字を把握できない。読みと書きでも能力が異なる。

## Decision

- 集計キーを「漢字 × reading/writing」とする。
- 累計ミスと、出題順位用の苦手度0〜10を分ける。
- 初回正解は苦手度-1、最初の誤答または「分からない」は+1とし、1回の問題遭遇で更新は1回だけ行う。
- 読みは熟語の `targetKanji` 全字を同じ結果で更新する。
- 書きは一字ごとの判定結果で個別更新する。
- 回答履歴を正本、漢字別集計を再計算可能な派生データとする。

## Consequences

- 異なる問題で同じ漢字を使っても、漢字単位で苦手を追跡できる。
- 読みでは誤りの原因字を特定せず、熟語の全構成漢字が連帯責任になる。
- 履歴、セッション、集計を同一トランザクションで更新し、二重計上を防ぐ必要がある。
