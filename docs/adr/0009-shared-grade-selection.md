# ADR-0009: 学年選択を教科横断の保存設定にする

- Status: Accepted
- Date: 2026-08-27

## Context

学年の選択は自由練習の画面内ローカル状態にしかなく、再読み込みで既定へ戻り、「今日の漢字」にも単位にも影響しなかった。単位の問題も学年を持ち（3年165問・4年50問）、今後の教科も同じ学年の概念を持つ。教科ごとに別々の学年選択を作ると、同じことを何度も選ばせることになる。

保護者設定には既に未履修の設定がある。漢字は字ごとの `learned`、単位は `category:grade` の未履修グループで、どちらも「まだ習っていない」を表す。学年選択と役割が重なるため、優先関係を決めないと「4年生を選んだのに未履修の漢字が出る」といった事故になる。

## Decision

- 学年選択を単一の教科横断設定とし、IndexedDBの既存 `settings` ストアへ `id: "grades"` として保存する。他のデータと同じ保存先で、ストア追加もスキーマ版の更新も伴わない（[ADR-0007](./0007-multi-subject-data-model.md) の方針どおり）。
- 選択は複数可とし、既定は全学年（3・4年生）とする。
- 漢字と単位で同じ選択を共有する。教科ごとの学年選択は持たない。
- **未履修設定を優先する。** 学年選択と未履修設定はANDで評価し、学年選択が未履修設定を上書きすることはない。4年生を選んでも、未履修の漢字・単位グループは出題されない。
- 学年選択は子どもがホームで変える前提の設定、未履修設定は保護者が保護者設定で変える前提の設定として分ける。
- 選択が空のときは出題しない。ホームと自由練習で「学年を選んでね」を表示する。

評価の順序を固定する。

| 段階 | 判定 | 適用箇所 |
|---|---|---|
| 1 | 未履修を除外 | 漢字は `learned === false`、単位は未履修グループ |
| 2 | 学年選択で絞る | `question.grade` が選択に含まれるか |
| 3 | 苦手枠・カバレッジ枠へ振り分け | [ADR-0008](./0008-weak-slot-mixing.md) |

## Consequences

- 学年を1回選べば、今日の漢字・今日の単位・自由練習のすべてに効く。
- 学年を絞ると出題候補が減る。3年生だけを選ぶと4年生の漢字は今日の学習にも出ない。
- 学年選択は学習履歴ではなく設定なので、バックアップ・復元・初期化の対象に含める（[ADR-0006](./0006-motivation-points-and-pet.md) のポイント残高と同じ扱い）。
- 未履修設定が優先されるため、保護者が未履修にした範囲は子どもの操作では出せない。意図した制約である。
