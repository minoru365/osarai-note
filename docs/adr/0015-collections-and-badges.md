# ADR-0015: がんばり記録に図鑑とバッジを足す

- Status: Accepted
- Date: 2026-11-26

## Context

がんばり記録は学習日数、漢字の得意・苦手、最近7日、単位、育てた仲間を数字と一覧で見せていたが、集めたもの・これから集められるものが見えず、子どもが「集める」楽しさを感じにくかった。利用者は、仲間図鑑、漢字図鑑、単位図鑑、日本地図の塗りつぶし、バッジのすべてを望んだ。

[ADR-0012](./0012-motivation-fairness-and-fantasy-progression.md) は、連続日数、順位、抽選報酬、失敗による減点を入れないこと、ポイントは完了した問題1問につき1だけ増えることを決めている。

## Decision

- がんばり記録を「きろく」（従来の内容）「ずかん」「バッジ」のタブに分ける。タブは `role="tablist"`・`aria-selected`・左右キー移動に対応し、選択を色・背景・下線で示す。
- 図鑑とバッジは既存の保存データ（回答履歴、漢字の集計、ポイントとペット、学年、単位の未習設定）と問題パックから**表示時に計算する**。ストアも記録も増やさないので、バックアップの対象（[ADR-0014](./0014-backup-restore-reset.md)）は変わらない。計算は `src/collections.ts`。
- **「あつめた」は一度付いたら消えない。** 苦手度のように上下する値は使わない。
  - 漢字：読みと書きの両方で、1回目に正解したことがある（`firstTryCorrect` がどちらも1以上）。きろくの「できるようになった漢字」（苦手度0、上下する）とは別の数え方で、画面では「あつめた」と呼び分ける。
  - 単位：その単位を使う問題（`requiredUnits`）のうち、1回目に正解した問題が3問以上。
  - 都道府県：その県の問題で1回目に正解したことがある。県は回答の問題IDから問題パックを引いて求める。
  - 仲間：育て終えた仲間は5段階すべて、育成中の仲間は今の段階まで絵を見せ、まだの段階は影で見せる。
- **子どもに届かないものを失敗のように見せない。** アプリに問題がまだ無いものは「じゅんびちゅう」、未習に設定したもの・選んでいない学年の単位は「まだならっていない」として、別の見た目にする。漢字図鑑は選んでいる学年だけを表示する。日本地図は4年生を選んでいないとき、集めた県は残したまま他を「まだならっていない」にする。集めた数の分母から「じゅんびちゅう」を除く。
- 問題パックの読み込みに失敗したときは、その図鑑だけ「読み込めませんでした」と出し、画面の他の部分は使えるようにする。今の問題パックに無い問題の回答は数えずに飛ばす。
- **バッジは累計だけで決め、消えない。** といた問題数（やり直しは同じ問題として1回）、学習した日数、漢字・単位・都道府県の集めた数、育てた仲間の数。集める系の最後のバッジは、用意できている数を目標にする。バッジでポイントやエサは増えない。
- 図鑑の日本地図は見るだけにする。拡大・移動・選択を無効にし、`touch-action` を戻して、指でなぞるとページがスクロールするようにする。

## Consequences

- 新しい教科や問題を足すと、図鑑の分母とバッジの最後の目標が自動で変わる。
- 漢字図鑑は2学年で最大402字を並べるため、スマートフォンでは縦に長くなる。
- 「あつめた」は1回目の正解で決まるため、苦手が戻っても図鑑からは消えない。苦手の確認は「きろく」と出題側（[ADR-0008](./0008-weak-slot-mixing.md)）が担う。

## 追記（2026-11-27）：出題から外した単位の問題

単位の問題を難しくした際、それまでの機械生成問題の多くを出題から外した。単位図鑑は回答の問題IDから使う単位を求めるため、外した問題を消すと集めた単位の色が消えてしまう。そこで単位パックに `retiredQuestions`（ID・系統・形式・使う単位）を累積で残し、図鑑は出題中の問題と退役した問題の両方から単位を引く。出題できるかどうかの判断（じゅんびちゅう・まだならっていない）は出題中の問題だけで行う。古い版のアプリはこの項目を読まないので、パックの読み込みは壊れない。
