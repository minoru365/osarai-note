# ADR-0004: 今日の漢字は練習回数の少ない順にする

- Status: Accepted
- Date: 2026-08-14

## Context

苦手度だけで今日の10問を選ぶと、一度も扱っていない漢字より同じ苦手漢字が繰り返されやすい。公開問題が増えた後も、履修済み漢字を広く練習できる必要がある。

## Decision

- 読み・書きそれぞれで、対象漢字の `presentations` が少ない問題を優先する。
- 複数字は対象字の最小 `presentations` を使い、練習の少ない字を含む問題を拾う。
- 同数なら対象字の最大 `weakness`、その後は日付・モード・セット番号による固定乱数で並べる。
- 未履修漢字を含む問題は候補から除外する。
- 作成済みの当日セットは変更せず、次に作るセットから新規則を適用する。

## Consequences

- 履修済み漢字を広く一巡しやすい。
- 苦手問題だけに偏らず、同じ練習回数の中では苦手度も維持できる。
- 既存の当日セットは再開互換のため旧順序のまま残る。
