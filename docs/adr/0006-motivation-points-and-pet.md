# ADR-0006: 教科横断ポイントとペット育成によるモチベーション機能

- Status: Accepted
- Date: 2026-08-25

## Context

今後、漢字以外の教科（単位、分数、日本地図、理科）を追加する計画があり、モチベーション機能は特定の教科に依存しない形で設計する必要がある。既存の漢字別苦手度集計（ADR-0002）は「漢字 × 読み/書き」という教科固有のキーであり、そのままではモチベーション用途に転用できない。

また、放置時に評価を下げる（成長を後退させる、ポイントを減らす）方式は、対象が低学年〜中学年の家庭学習者であることを踏まえると、罪悪感やプレッシャーにつながりやすく、2章の学習体験の原則（不正解を責める表現を使わない）とも相性が悪い。

## Decision

- ポイントは教科・問題種別に依存しない単一の残高として持つ。読み・書きいずれの問題でも、回答が確定すれば正誤や「分からない」を問わず1ポイントを加算する。将来の教科追加時も同じ加算規則を適用する。
- ペットの育成状態（種類、現在の段階、これまでの投入ポイント、育成済みペット履歴）は、漢字別集計とは別の独立したストアに保持する。既存の回答履歴・セッション・漢字別集計のスキーマは変更しない。
- 成長段階は「投入ポイント ÷ 100」から導出する値とし、段階そのものを直接書き換えない。1匹あたり最大500ポイントで5段階に達する。
- しょんぼり表示は永続データとして保存せず、「最終回答日時」から都度計算する派生表示とする（今日との差が3日以上でしょんぼり）。これにより日付計算のずれがあっても学習履歴や育成進捗を壊さない。しょんぼり自体はポイント・段階を後退させない。
- エサは即時消費型とし、在庫を持たない。エサ選択時にその場でポイント残高から差し引き、成長判定を更新する。
- ポイント残高とペット育成状態は、保護者機能のJSONバックアップ・復元・初期化の対象に含める。

## Consequences

- 新しいIndexedDBストア（ポイント残高、ペット育成状態）の追加が必要になり、AGENTS.mdの規則に従って既存データを保持する移行テストを先に作る必要がある。
- ポイント加算ロジックを既存の回答保存トランザクション（読み・書き・自由練習すべて）に組み込む必要があり、既存の「回答履歴・セッション・漢字別集計を同一トランザクションで確定する」実装（ADR-0002）と足並みをそろえる。
- しょんぼり判定を非永続の派生値にしたことで、実装は「最終回答日時さえ正しく保存されていればよい」という単純な形になり、専用のバッチ処理や日次リセット処理は不要になる。
- 教科追加時にポイント加算規則を変更する必要がなく、モチベーション機能と教科別コンテンツ設計を独立して進められる。
- ペットの成長段階×2種類×（通常2枚絵＋しょんぼり専用絵）の絵素材を、教科コンテンツとは別に用意する作業が発生する。
