# ADR-0003: 読み・書き各10問の当日セッション

- Status: Accepted
- Date: 2026-08-14

## Context

約10分で取り組める量にしつつ、読みと書きを上部タブで自由に切り替えたい。途中でホームへ戻った場合も、確定済み回答を失いたくない。

## Decision

- 読み10問、書き10問を独立した当日セットとして管理する。
- 初期順序はADR-0004で変更し、練習回数の少ない漢字を優先する。
- セット作成時に問題順を固定し、当日中は途中再開する。
- 同一セットでは対象漢字の重複を避け、候補不足時だけ許す。
- 完了後は当日未出題を優先した「もう10問」を許す。
- 読み完了後に書きへ自動移動しない。

## Consequences

- 進捗が予測しやすく、タブ切替で学習を中断しない。
- 読みと書きは異なる問題セットになる場合がある。
- 当日セッション、問題項目ID、日付変更、追加セットを保存するデータモデルが必要になる。
