# ADR-0001: ローカルファーストPWAとGitHub Pages

- Status: Accepted
- Date: 2026-08-13

## Context

家庭内のXiaomi Pad 6で使い、学習履歴を残したい。Azureサブスクリプションはあるが、初期版でアカウント、認証、クラウド同期を運用する必要はない。

## Decision

- React製PWAをGitHub Pagesから静的配信する。
- 学習履歴、履修設定、カスタム問題、設定は端末内IndexedDBへ保存する。
- Service Workerでアプリと問題パックをキャッシュする。
- 初期版は認証、バックエンド、クラウド同期を持たない。
- 端末移行には保護者操作のJSONバックアップ・復元を用意する。

## Consequences

- 配信と運用が簡単で、学習データを外部送信しない。
- ブラウザデータ消去や端末故障への備えとして、バックアップが必須になる。
- 複数端末同期が必要になった場合は、認証・所有権・削除仕様から再設計する。
