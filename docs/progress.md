## 次に実装する

### M1：毎日の漢字学習

1. 読み・書き各10問の候補選定と順序固定
2. 既存の読み・書き回答を当日セッション保存APIへ接続
3. ホーム進捗、当日再開、完了画面、もう10問
4. Xiaomi Pad 6で一連の実機確認

### M2：問題生成

1. 3・4年生の音訓読み基準一覧を確定
2. 共通素材スキーマと生成スクリプトを作成
3. 学年超過漢字のひらがな化と機械検査
4. レビュー一覧を作成し、確認済み問題だけを公開
