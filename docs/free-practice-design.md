# 自由練習の保存境界

最終更新：2026-08-14

## 状態と操作

| 操作 | 今日のセット | 回答履歴・漢字別苦手度 |
|---|---|---|
| 自由練習一覧を開く | 変更しない | 変更しない |
| 学年または漢字から練習セットを開始する | 変更しない | 変更しない |
| 正解まで回答する | 変更しない | 1回の提示として原子的に反映 |
| 未履修漢字を含む問題 | 表示・回答確定を拒否 | 変更しない |
| 同じ回答IDを再送する | 変更しない | 同一内容は成功扱い、別内容は拒否 |

## 一覧と出題

- 上部固定エリアに学年選択と「ランダム10問で練習開始」を置く。
- 下部は問題の有無にかかわらず、未履修を除く選択学年の全漢字を縦スクロールで表示し、ページングしない。
- 各漢字に読み・書きの苦手度0〜10を棒グラフで表示する。
- 練習開始では選択学年の問題ペアをランダム順に並べ、先頭10問で自由練習セットを開始する。
- 漢字を選ぶと問題選択を挟まず、その漢字を `targetKanji` に含む問題ペアから最大10問の自由練習セットを開始する。
- 一覧では読み／書きを選ばない。回答画面上部のタブで同じ `pairId` の読み・書きを切り替える。
- 未履修の漢字を含む問題は、選択漢字が履修済みでも候補から除外する。
- 確認済み問題がない漢字は一覧で「問題準備中」と表示し、開始できない。

## 不変条件

- 自由練習は `sessionId: free-practice` で回答履歴へ保存し、当日セッションを作成・更新しない。
- 読み問題は、正解するまでの誤答をまとめて1回の提示として苦手度へ反映する。
- 書き問題は、文字別のミス・見本利用を既存の書き集計規則で反映する。
- 一覧表示時に未履修を除外し、回答確定トランザクション内でも履修状態を再検査する。
- 回答、対象漢字すべての集計更新は同じIndexedDBトランザクションで確定する。

## 機械ゲート

- 未履修漢字を1字でも含む問題の一覧除外
- 未履修へ変更された後の回答拒否と全更新ロールバック
- 正誤の苦手度反映、回答履歴保存、当日セッション非作成
- 同一回答IDの再試行による二重計上防止と競合内容の拒否

## 人による確認

- ホームから自由練習一覧へ移動できる
- 学年選択と練習開始ボタンが固定され、漢字一覧だけを縦スクロールできる
- 学年の練習開始でランダム最大10問が開く
- 漢字を選ぶと問題選択を挟まず、関連する最大10問が開く
- 回答後の「次へ」でセット内を進み、最後は自由練習一覧へ戻る
