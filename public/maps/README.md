# 日本地図SVG

`japan-prefectures.svg` は [PA4KEV/japan-vector-map](https://github.com/PA4KEV/japan-vector-map) の `japan-prefectures.svg` を使用しています。

アプリでは、元SVGの `inkscape:label` を都道府県の識別子として利用します。地図の表示とクリック判定用に使うもので、測量や行政用途には使用しません。
